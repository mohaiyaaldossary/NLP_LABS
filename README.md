# NLP Labs 1–6

Natural Language Processing lab submissions by Mohaiya aldossary (2230004579).

Each lab folder contains the completed Jupyter notebook and its submission PDF.

## Datasets

Large datasets for Labs 1–5 are downloaded separately. The supplied Simpsons and Yelp datasets for Labs 5 and 6 are included. The notebooks include their required setup and use these public sources:

- Lab 1: [IMDB Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)
- Lab 2: [Apple Twitter Sentiment Texts](https://www.kaggle.com/datasets/seriousran/appletwittersentimenttexts)
- Lab 3: [Large Random Tweets from Pakistan](https://www.kaggle.com/datasets/adizafar/large-random-tweets-from-pakistan)
- Lab 4: [Disneyland Reviews](https://www.kaggle.com/datasets/arushchillar/disneyland-reviews) and [Amazon Reviews: Unlocked Mobile Phones](https://www.kaggle.com/datasets/PromptCloudHQ/amazon-reviews-unlocked-mobile-phones)

- Lab 5: [Fake and Real News Dataset](https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset); `True.csv` downloads automatically when missing. The supplied `simpsons_script_lines.csv` is included.
- Lab 6: The supplied `07-yelp-dataset.txt` is included.

## Running Labs 5 and 6

Open each notebook from its own lab folder and run all cells from a fresh Python kernel. The first code cell installs the required packages with `%pip`. Lab 5 downloads its required NLTK tokenizer data. Internet access is required for initial setup and the news dataset download.
